
# 🎨 AI Comic Strip Generator

An AI-powered web application that converts user-provided stories into visually engaging comic strips with multiple panels, illustrations, speech bubbles, and captions.

## ✨ Features

- Convert text stories into structured comic panels.
- AI-powered story breakdown into 4–8 panels.
- Generate illustrations for each comic panel.
- Support multiple visual styles, including Manga, Western Comic, Watercolor, and Pixel Art.
- Automatically display dialogue using speech bubbles.
- Add captions and narration to panels.
- Preview the complete comic strip.
- Export comics as PNG images and PDF documents.

## 🛠️ Technologies Used

**Frontend**
- React.js
- CSS

**Backend**
- Node.js
- Express.js

**AI & APIs**
- Google Gemini API – Story and panel generation
- Hugging Face FLUX – AI image generation

**Other Tools**
- html2canvas – PNG export
- jsPDF – PDF export

## 🚀 How to Run the Project

### 1. Clone the Repository

```bash
git clone <your-github-repository-link>
cd <project-folder>
```

### 2. Start the Backend

```bash
cd backend
npm install
node server.js
```

### 3. Start the Frontend

Open another terminal:

```bash
cd frontend
npm install
npm run dev
```

Open the local URL displayed in the terminal.

## 📌 Project Workflow

1. Enter a story in the text area.
2. Select the desired comic style and number of panels.
3. Generate the comic storyboard using AI.
4. Generate illustrations for each panel.
5. View speech bubbles, captions, and narration.
6. Download the completed comic as a PNG or PDF.
